# Project Rules & Domain Guidelines

Project ID: test-plant-robot
Title: Design a plant watering robot with

1. Component selections must be documented in `bom/bom.json`.
2. Pinouts and power lines must match between `wiring/wiring.json` and `code/src/main.cpp`.
3. Firmware code must be modular, well-commented, and target Arduino/PlatformIO framework.
4. Enclosures must be parametric in `enclosure/case.scad`.
