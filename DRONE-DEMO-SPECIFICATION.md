This document specifies the complete demo conversation for the drone project.

- **Project**: Farm Patrol Autonomous Drone
- **Budget**: $350 target, $308 estimated
- **Messages**: 20+ with extensive AI responses
- **Artifacts**: MVP, PRD, Context, Architecture, BOM, Wiring, Code, Enclosure

## Message Flow

### 1. User: Initial Request (Short)
```
I want to build a DIY autonomous drone that can patrol my farm, stream video to my phone, and return to its charging station automatically.
```

### 2. AI: MVP Generation (EXTENSIVE - 950 tokens)
- Project vision
- Scope (included/excluded features in tables)
- Success criteria table
- Risk matrix
- Technology stack
- Creates MVP artifact

### 3. User: Approval (Short)
```
Yes, create the PRD and technical architecture.
```

### 4. AI: PRD Generation (HUGE - 1200 tokens)
- Executive summary
- User personas (3-4)
- Functional requirements (FR-001 through FR-015)
- Non-functional requirements
- Use cases
- Risk analysis
- Creates PRD artifact

### 5. User: Context Request (Short)
```
Generate project context document.
```

### 6. AI: Context Document (LARGE - 800 tokens)
- Business goals
- Stakeholders
- Constraints
- Assumptions
- System boundaries
- Creates Context artifact

Create technical architecture and generate BOM.
